# PARSA & SABA

A short interactive cinematic engagement invitation. Start at [`PROJECT.md`](PROJECT.md).

## Prototype — The Between

Beat 2 only. Scroll is the timeline.

```bash
npm install
npm run dev
```

Open `http://localhost:5173/` on a phone (same Wi-Fi; Vite prints a Network URL).

The first screen is obsidian black. Scroll.

| Query | Effect (dev only) |
|---|---|
| `?tier=full` | Force the WebGL beat |
| `?tier=reduced` | Simplified shader, DPR 1 |
| `?tier=static` | No WebGL; CSS fallback |

Wording, colours, and typeface are **provisional** (O-01, O-11, O-09).
